# Phase 2 执行计划：虚拟环境内置 Google WebView

## 阶段目标
将 `com.google.android.webview` APK 打包进 BlackBox，在虚拟环境中通过 DexClassLoader 加载，使所有分身应用统一使用 Google WebView，彻底解决 Honor/Huawei/Xiaomi 等厂商 WebView 兼容性问题。

## 前置条件
- 已阅读 `CLAUDE.md` 了解项目架构
- 已阅读 `RESEARCH-phase2.md` 了解方案分析
- gsd-sdk 已修复可用（v1.39.0-rc.4）
- 当前分支: `feature-hwp`


2. **ClassLoader 创建逻辑**:
   ```java
   File apkFile = new File(webviewDir, "webview.apk");
   ```

**验收标准**:

- 失败时（APK 损坏/不存在）gracefully 降级，不影响 App 启动

### Task 2: 增强 WebViewFactoryProxy

**目标**: 当用户开启内置 WebView 时，Hook `getWebViewProviderClass()` 和 `getWebViewProviderClassLoader()` 返回内置 APK 的类/ClassLoader。

**文件变更**:

`Bcore/src/main/java/top/niunaijun/blackbox/fake/service/WebViewFactoryProxy.java`

1. **修改 `GetWebViewProviderClass`**:
   ```java
   @Override
   protected Object hook(Object who, Method method, Object[] args) throws Throwable {
       // 优先使用内置 WebView
       if (BlackBoxCore.get().getClientConfiguration().isUseBuiltinWebView()) {
           BWebViewEnvironment env = BWebViewEnvironment.get();
           if (env.isReady()) {
               try {
                   Class<?> providerClass = env.getWebViewProviderClass();
                   Slog.d(TAG, "Using builtin WebView provider: " + providerClass);
                   return providerClass;
               } catch (ClassNotFoundException e) {
                   Slog.w(TAG, "Builtin WebView provider class not found, falling back", e);
               }
           }
       }
       // 原有 fallback 逻辑
       ...
   }
   ```

2. **修改 `GetWebViewProviderClassLoader`**:
   ```java
   @Override
   protected Object hook(Object who, Method method, Object[] args) throws Throwable {
       if (BlackBoxCore.get().getClientConfiguration().isUseBuiltinWebView()) {
           BWebViewEnvironment env = BWebViewEnvironment.get();
           if (env.isReady()) {
               ClassLoader loader = env.getWebViewClassLoader();
               if (loader != null) return loader;
           }
       }
       // 原有 fallback
       ...
   }
   ```

3. **保留原有 fallback**: 当内置 WebView 未就绪或用户未开启时，保持现有行为

**验收标准**:
- 开启内置 WebView 后，日志输出 `WebViewFactory: Using builtin WebView provider`
- 关闭内置 WebView 后，保持原有行为不变
- 内置 WebView 未就绪时，自动 fallback 到系统 WebView

### Task 7: 构建脚本（APK 下载/校验）

**目标**: 在构建时自动获取并校验 Google WebView APK。

**方案选择**:

**方案 A：手动放置（推荐，简单可控）**
1. 开发者手动下载 `com.google.android.webview` APK
2. 放入 `app/src/main/assets/webview/webview.apk`
3. 在 `app/build.gradle` 中校验文件存在性和大小

```gradle
android {
    // ...
    sourceSets {
        main {
            assets.srcDirs += ['src/main/assets']
        }
    }
}

// 构建时检查
task checkWebViewApk {
    doFirst {
        def apk = file('src/main/assets/webview/webview.apk')
        if (!apk.exists() || apk.length() < 10_000_000) {
            throw new GradleException(
                "WebView APK missing or too small. " +
                "Download from https://www.apkmirror.com/apk/google-inc/android-system-webview/ " +
                "and place at app/src/main/assets/webview/webview.apk"
            )
        }
    }
}
preBuild.dependsOn checkWebViewApk
```

**方案 B：自动下载**
```gradle
task downloadWebViewApk {
    doLast {
        def apkFile = file('src/main/assets/webview/webview.apk')
        if (!apkFile.exists()) {
            apkFile.parentFile.mkdirs()
            // 从配置 URL 下载
            new URL(project.ext.webviewApkUrl).withInputStream { i ->
                apkFile.withOutputStream { it << i }
            }
            // 校验 SHA256
            def sha256 = ...
            if (sha256 != project.ext.webviewApkSha256) {
                throw new GradleException("WebView APK SHA256 mismatch!")
            }
        }
    }
}
```

**推荐方案 A** — 自动下载依赖外部 URL，不可靠。手动放置 + 构建校验更可控。

**文件变更**:
1. `app/build.gradle` — 添加 `checkWebViewApk` task
2. `app/.gitignore` — 忽略 `src/main/assets/webview/*.apk`（APK 太大，不提交到 git）
3. `README.md` 或 `Docs.md` — 添加 WebView APK 获取说明

**验收标准**:
- 缺少 APK 时构建失败，提示清晰的错误信息
- APK 存在时构建通过
- APK 不被提交到 git（.gitignore）

## 风险与对策

| 风险 | 对策 |
|------|------|
| 内置 APK 体积过大（+40MB） | ABI 分离构建；只打包目标架构；APK 不提交 git |
| WebView 版本滞后 | 定期更新内置 APK；允许用户切换回系统 WebView |
| ClassLoader 冲突 | 使用独立 DexClassLoader；与宿主 ClassLoader 隔离 |
| ROM 阻止非系统 WebView | 保留系统 WebView fallback；设置开关可随时关闭 |
| 安全漏洞无法及时修复 | 用户可选择切换回系统 WebView（接收系统更新） |
| APK 分发合规性 | Google WebView 是开源的（BSD-like），可自由分发 |
