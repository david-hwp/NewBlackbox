<objective>
Strip the `app` module of all direct Bcore dependencies and replace them with AIDL calls through `EngineProxy`. Implement the dynamic loading layer (`EngineLoader`) that extracts and loads the Engine APK at runtime. Refactor all 43 direct `BlackBoxCore` / `BPackageManager` / `BLocationManager` calls in the app module to use the IPC layer.

Purpose: This phase converts the monolithic architecture into a true client-server model where the main APK is a thin client and the Engine is a remote service.

Output: A main APK that can dynamically load the Engine APK and perform all virtual app operations via AIDL, with zero direct Bcore imports in the app module.
</objective>

    4. `initBlackBoxCore` must use reflection to:
       - Load `BlackBoxCore` class from DexClassLoader
       - Call `BlackBoxCore.get()`
       - Call `doAttachBaseContext(context, config)` via reflection
       - Call `doCreate()` via reflection
    5. All operations must be wrapped in try-catch with detailed logging
  </description>
