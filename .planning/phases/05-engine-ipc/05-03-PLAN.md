<objective>
Implement the built-in Engine delivery mechanism and online upgrade system. The main APK must contain a default Engine APK in its assets, automatically install it on first launch, and support online upgrades with atomic replace and automatic rollback on failure.

Purpose: Users should be able to install the main APK from scratch and have a working Engine without manual steps. Future Engine updates should be seamless and safe.

Output: A main APK with embedded Engine, automatic first-time installation, and a robust online upgrade pipeline.
</objective>

  <files>
    app/src/main/java/top/niunaijun/blackboxa/engine/EngineInstaller.kt
  </files>
  <description>
    1. Create `EngineInstaller` object with methods:
       - `isEngineInstalled(context: Context): Boolean`
         - Check if Engine APK is installed as a separate app
         - Try `context.packageManager.getPackageInfo(ENGINE_PACKAGE, 0)`
       - `getInstalledEngineVersion(context: Context): Int`
         - Return installed Engine's versionCode, or 0 if not installed
       - `installFromAssets(context: Context): Result<Unit>`
         - Copy `assets/engine/engine-base.apk` to `context.filesDir/engine/engine-base.apk`
         - Use `PackageManager` to install the APK
         - On Android 10+: use `PackageInstaller` API with intent receiver
         - On older: use `Intent.ACTION_VIEW` with `application/vnd.android.package-archive`
         - Verify signature after installation
       - `getBuiltinEngineVersion(context: Context): Int`
         - Extract versionCode from the bundled APK without installing
         - Use `PackageManager.getPackageArchiveInfo()`
    2. Installation must be atomic:
       - Copy to temp file first
       - Verify MD5 / signature
       - Then trigger install
       - On failure, clean up temp file
    3. Handle "install unknown apps" permission:
       - Check `canRequestPackageInstalls()`
       - If not granted, redirect to settings
       - Show explanatory dialog before redirect
  </description>
</task>

<task type="auto">
  <name>Task 3: Implement EngineVersionChecker</name>
  <files>
    app/src/main/java/top/niunaijun/blackboxa/engine/EngineVersionChecker.kt
  </files>
  <description>
    1. Create `EngineVersionChecker` with:
       - `checkForUpgrade(context: Context): UpgradeInfo?`
    2. Flow:
       a. Get local version: `EngineInstaller.getInstalledEngineVersion()`
       b. Get builtin version: `EngineInstaller.getBuiltinEngineVersion()`
       c. Call server API: `GET /api/engine/latest_version`
          - Request: `{ "current_version": localVersion, "app_version": BuildConfig.VERSION_CODE }`
          - Response: `{ "version_code": 102, "version_name": "2.0.1", "url": "...", "force": false, "min_app_version": 400 }`
       d. Compare versions:
          - If `response.version_code > max(local, builtin)` → upgrade available
          - If `response.force && response.version_code > local` → force upgrade
          - If `BuildConfig.VERSION_CODE < response.min_app_version` → app too old, block usage
    3. Return `UpgradeInfo` containing:
       - `versionCode`, `versionName`, `downloadUrl`, `isForce`, `changelog`
    4. Cache result for 5 minutes to avoid repeated checks
    5. Handle network errors gracefully (silent fail, retry next launch)
  </description>
</task>

<task type="auto">
  <name>Task 4: Implement EngineUpgradeManager</name>
  <files>
    app/src/main/java/top/niunaijun/blackboxa/engine/EngineUpgradeManager.kt
  </files>
  <description>
    1. Create `EngineUpgradeManager` with:
       - `downloadAndInstall(context: Context, upgradeInfo: UpgradeInfo): Result<Unit>`
    2. Download flow:
       a. Show progress notification (download %)
       b. Download to `context.cacheDir/engine-update/engine-{version}.apk`
       c. Verify file integrity (MD5 / SHA256 from server response)
       d. Verify APK signature fingerprint matches trusted whitelist
       e. Verify `minSdkVersion` <= device SDK
    3. Atomic replacement flow:
       a. Stop all virtual apps (kill Engine processes)
       b. Unbind from Engine Service
       c. Backup current Engine APK:
          - Rename installed APK to `engine-backup-{version}.apk`
       d. Install new Engine APK via PackageInstaller
       e. Wait for install completion (via broadcast receiver)
       f. Verify new Engine responds to bindService
       g. If bind fails within 30 seconds → rollback
    4. Rollback flow:
       a. Reinstall backup APK
       b. Delete corrupted new APK
       c. Notify user "Upgrade failed, restored to previous version"
    5. Cleanup:
       a. Delete downloaded APK after successful install
       b. Delete old backup after new version confirmed working
    6. All operations on background thread (Coroutine / AsyncTask)
  </description>
</task>
