<objective>
Create the `:engine-plugin` module as a standalone Android Application (APK) that packages the entire Bcore engine. Set up the unified AIDL entry point `IBlackBoxEngine`, migrate all Bcore source code, and adapt the initialization flow for headless (no-UI) operation.

Purpose: This is the foundational layer that all IPC communication depends on. The Engine APK must be installable as a separate application, expose its capabilities exclusively via AIDL, and initialize all native hooks within its own process.

Output: A buildable `:engine-plugin` module that produces a signed APK containing the complete engine runtime.
</objective>
