# Phase 8 Wave 3 计划：APK 与后端接口对接

> Wave 归属: Phase 8 — 主 APK 改造为多店管家
> 前置依赖: 08-PLAN.md (Wave 1 — Android UI), 08-02-PLAN.md (Wave 2 — 后端 API)
> 执行顺序: 必须在 Wave 1 P0 完成后开始，可与 Wave 2 并行开发，最终联调

---

## 目标

在 Android APP 端建立完整的网络通信层，通过 Retrofit + OkHttp 对接 Wave 2 规划的后端 API，实现「登录 → 获取店铺列表 → 算力赠送 → 交易日志 → 用户反馈」完整数据流。

**范围**：`app` 模块新增网络层 + Repository 层改造 + ViewModel 层对接。不涉及 UI 布局变更（已在 Wave 1 完成）。

## 任务分解

### P0 — 网络层基础（必须先完成）

#### Task 1: 添加网络依赖
- **文件**:
  - `app/build.gradle` — 新增依赖
- **新增依赖**:
  ```groovy
  implementation 'com.squareup.retrofit2:retrofit:2.9.0'
  implementation 'com.squareup.retrofit2:converter-gson:2.9.0'
  implementation 'com.squareup.okhttp3:okhttp:4.12.0'
  implementation 'com.squareup.okhttp3:logging-interceptor:4.12.0'
  ```
- **交付标准**: `./gradlew :app:dependencies` 可解析到上述库，编译通过

#### Task 2: Token 管理器
- **文件**:
  - `app/src/main/java/.../data/TokenManager.kt`
- **功能**:
  - `saveToken(token: String)` — 保存到 EncryptedSharedPreferences
  - `getToken(): String?` — 读取 token
  - `clearToken()` — 清除 token（退出登录）
  - `saveUser(user: UserDto)` — 保存登录用户信息
  - `getUser(): UserDto?` — 读取用户信息
- **交付标准**: 登录后 token 持久化，App 重启后仍可用

#### Task 3: Retrofit 客户端封装
- **文件**:
  - `app/src/main/java/.../network/RetrofitClient.kt` — Retrofit 单例
  - `app/src/main/java/.../network/AuthInterceptor.kt` — Token 注入拦截器
  - `app/src/main/java/.../network/ApiService.kt` — 所有 API 接口定义
- **ApiService 接口**:
  ```kotlin
  interface ApiService {
      @POST("auth/login")
      suspend fun login(@Body request: LoginRequest): ApiResponse<UserDto>

      @GET("shops/my")
      suspend fun getMyShops(): ApiResponse<List<ShopDto>>

      @POST("shops/report")
      suspend fun reportShop(@Body request: ShopReportRequest): ApiResponse<ShopReportResult>

      @POST("compute/gift")
      suspend fun giftCompute(@Body request: GiftRequest): ApiResponse<GiftResult>

      @Multipart
      @POST("feedbacks")
      suspend fun submitFeedback(
          @Part("content") content: String,
          @Part images: List<MultipartBody.Part>,
          @Part logFile: MultipartBody.Part?
      ): ApiResponse<FeedbackDto>

      @GET("logs/my")
      suspend fun getMyLogs(
          @Query("type") type: String? = null,
          @Query("page") page: Int = 1,
          @Query("size") size: Int = 20
      ): ApiResponse<PagedResult<LogEntryDto>>

      @PUT("users/me/username")
      suspend fun updateUsername(@Body request: UpdateUsernameRequest): ApiResponse<UserDto>

      @PUT("users/me/password")
      suspend fun updatePassword(@Body request: ChangePasswordRequest): ApiResponse<Unit>
  }
  ```
- **交付标准**: 每个接口可通过单元测试（MockWebServer）验证请求格式正确

#### Task 4: 统一响应包装类
- **文件**:
  - `app/src/main/java/.../network/ApiResponse.kt`
- **结构**:
  ```kotlin
  data class ApiResponse<T>(
      val code: Int,
      val message: String,
      val data: T?
  )

  data class PagedResult<T>(
      val total: Int,
      val page: Int,
      val size: Int,
      val list: List<T>
  )
  ```
- **交付标准**: Gson 可正确序列化/反序列化后端返回的 JSON

#### Task 12: HomeViewModel 改造
- **文件**:
  - `app/src/main/java/.../view/home/HomeViewModel.kt`
- **功能**:
  - `loadShops()` — 调用 ShopRepository.getMyShops()
  - `reportShop(shop: ShopDto)` — 分身应用启动时上报店铺数据
  - `shopsLiveData: LiveData<List<ShopDto>>` — 驱动首页店铺列表
  - `computeBalanceLiveData: LiveData<Int>` — 驱动算力余额显示
- **与 UI 对接**: HomeActivity 观察 shopsLiveData，平台切换时过滤列表

#### Task 13: GiftViewModel

### P1 — Activity 层数据绑定

#### Task 16: LoginActivity 对接
- **改动**:
  - 输入框绑定 LoginViewModel
  - 点击登录 → `viewModel.login(phone, password)`
  - 观察 loadingLiveData → 显示/隐藏「登录中…」
  - 观察 errorLiveData → Toast 错误提示
  - 观察 loginResultLiveData → 保存 token → `HomeActivity.start(this)`

#### Task 17: HomeActivity 对接
- **改动**:
  - `onCreate` 中调用 `viewModel.loadShops()`
  - 观察 `shopsLiveData` → 更新 ShopListAdapter
  - 点击店铺卡片 → `EngineProxy.launchApk()` + `viewModel.reportShop(shop)`
  - 算力余额从 `user.computeBalance` 显示
  - 添加店铺成功后刷新列表

#### Task 18: GiftActivity 对接
- **改动**:
  - 表单提交前本地校验（手机号格式、数量 > 0）
  - 校验通过弹出二次确认 BottomSheet
  - 确认后调用 `viewModel.gift(toPhone, amount)`
  - 成功 → 按钮变绿 → 1.5s 后重置表单

#### Task 19: LogsActivity 对接
- **改动**:
  - `onCreate` 加载全部日志
  - 筛选标签切换 → `viewModel.loadLogs(type)`
  - 列表滑动到底部 → `viewModel.loadMore()`
  - 按日期分组渲染（UI 层逻辑）

#### Task 20: ProfileActivity 对接
- **改动**:
  - 用户卡片从 TokenManager 读取用户信息
  - 点击修改用户名 → BottomSheet → `viewModel.updateUsername()`
  - 点击修改密码 → BottomSheet → `viewModel.updatePassword()`
  - 问题反馈 → 调用 FeedbackRepository（文本+图片选择）
  - 退出登录 → `viewModel.logout()`

## 回滚计划

1. 若后端接口未就绪，Repository 层保留 Mock 实现开关：
   ```kotlin
   class ShopRepository(private val api: ApiService, private val mock: Boolean = false) {
       suspend fun getMyShops(): Result<List<ShopDto>> {
           return if (mock) mockShops() else api.getMyShops().toResult()
       }
   }
   ```
2. 网络层异常不影响 APP 基础功能（引擎 IPC 不依赖网络）
3. 所有 Repository 方法返回 `Result<T>`，调用方可选择忽略网络错误

```kotlin
abstract class BaseRepository(protected val api: ApiService) {
    protected suspend inline fun <T> safeApiCall(
        crossinline block: suspend () -> ApiResponse<T>
    ): Result<T> = try {
        val response = block()
        if (response.code == 200) {
            response.data?.let { Result.success(it) }
                ?: Result.failure(Exception("Empty response data"))
        } else {
            Result.failure(ApiException(response.code, response.message))
        }
    } catch (e: Exception) {
        Result.failure(e)
    }
}

class ApiException(val code: Int, message: String) : Exception(message)
```

### 修订 8: 新增店铺有效期校验机制（用户补充）

**业务规则**:
1. 首页店铺列表从本地 EngineProxy 直接展示
2. 用户点击店铺卡片时，必须先校验该店铺在服务端是否在有效期内
3. APK 本地缓存有效期数据，最长缓存 30 分钟
4. 30 分钟后自动重新请求服务器获取有效期数据并更新本地缓存
5. 获取失败或离线超过 30 分钟，提示用户重新登录以获得最新有效期数据
6. 目的：防止用户通过屏蔽网络绕过服务器校验持续使用

**新增组件**:
- `app/.../data/ShopValidityManager.kt`

```kotlin
// 有效期缓存数据结构
data class ValidityCache(
    val shopId: String,
    val expireAt: Long,        // 服务端返回的有效期截止时间（毫秒）
    val autoRenew: Boolean,    // 是否开启自动续期
    val cachedAt: Long         // 本地缓存时间（毫秒）
)

class ShopValidityManager(
    private val api: ApiService,
    private val prefs: SharedPreferences
) {
    companion object {
        const val CACHE_MAX_AGE_MS = 30 * 60 * 1000L  // 30 分钟
    }

    // 校验单个店铺是否可点击
    suspend fun validateShop(shopId: String): ValidationResult {
        val cache = loadCache(shopId)

        // 1. 本地缓存未过期（30 分钟内）
        if (cache != null && System.currentTimeMillis() - cache.cachedAt < CACHE_MAX_AGE_MS) {
            return if (cache.expireAt > System.currentTimeMillis()) {
                ValidationResult.Valid(cache.expireAt, cache.autoRenew)
            } else {
                ValidationResult.Expired(cache.autoRenew)
            }
        }

        // 2. 缓存已过期或不存在，请求服务端
        return try {
            val response = api.validateShops(listOf(shopId))
            val result = response.data?.firstOrNull()

            if (result != null) {
                saveCache(shopId, result.expireAt, result.autoRenew)
                if (result.isValid) {
                    ValidationResult.Valid(result.expireAt, result.autoRenew)
                } else {
                    ValidationResult.Expired(result.autoRenew)
                }
            } else {
                ValidationResult.Error("店铺信息获取失败")
            }
        } catch (e: Exception) {
            // 3. 请求失败且离线超过 30 分钟
            if (cache == null || System.currentTimeMillis() - cache.cachedAt >= CACHE_MAX_AGE_MS) {
                ValidationResult.RequireRelogin("网络异常，请重新登录以获取最新数据")
            } else {
                // 请求失败但缓存未超 30 分钟，按缓存结果处理
                if (cache.expireAt > System.currentTimeMillis()) {
                    ValidationResult.Valid(cache.expireAt, cache.autoRenew)
                } else {
                    ValidationResult.Expired(cache.autoRenew)
                }
            }
        }
    }

    // 批量刷新所有店铺有效期（App 启动时 / 回到前台时调用）
    suspend fun refreshAll(shopIds: List<String>) {
        try {
            val response = api.validateShops(shopIds)
            response.data?.forEach { result ->
                saveCache(result.shopId, result.expireAt, result.autoRenew)
            }
        } catch (e: Exception) {
            // 静默失败，不影响使用
            Log.w("ValidityManager", "批量刷新失败: ${e.message}")
        }
    }

    private fun saveCache(shopId: String, expireAt: Long, autoRenew: Boolean) {
        prefs.edit()
            .putLong("validity_expire_$shopId", expireAt)
            .putBoolean("validity_auto_$shopId", autoRenew)
            .putLong("validity_cached_$shopId", System.currentTimeMillis())
            .apply()
    }

    private fun loadCache(shopId: String): ValidityCache? {
        val cachedAt = prefs.getLong("validity_cached_$shopId", 0)
        if (cachedAt == 0L) return null
        return ValidityCache(
            shopId = shopId,
            expireAt = prefs.getLong("validity_expire_$shopId", 0),
            autoRenew = prefs.getBoolean("validity_auto_$shopId", false),
            cachedAt = cachedAt
        )
    }
}

sealed class ValidationResult {
    data class Valid(val expireAt: Long, val autoRenew: Boolean) : ValidationResult()
    data class Expired(val autoRenew: Boolean) : ValidationResult()
    data class Error(val message: String) : ValidationResult()
    data class RequireRelogin(val message: String) : ValidationResult()
}
```

**点击店铺时的完整流程**:
```kotlin
// HomeActivity 中点击店铺卡片
mAdapter.setItemClickListener { _, shop, _ ->
    lifecycleScope.launch {
        when (val result = validityManager.validateShop(shop.shopId)) {
            is ValidationResult.Valid -> {
                // 在有效期内，直接启动分身
                viewModel.launchApk(shop.packageName)
                // 异步上报（扣算力）
                viewModel.reportShop(shop)
            }
            is ValidationResult.Expired -> {
                if (result.autoRenew) {
                    // 自动续期：扣减算力后启动
                    val deductResult = viewModel.renewShop(shop)
                    if (deductResult.isSuccess) {
                        viewModel.launchApk(shop.packageName)
                    } else {
                        toast("自动续期失败：算力不足")
                    }
                } else {
                    // 手动续期弹窗
                    showRenewDialog(shop)
                }
            }
            is ValidationResult.RequireRelogin -> {
                // 离线超过 30 分钟，强制重新登录
                AlertDialog.Builder(this@HomeActivity)
                    .setTitle("需要重新登录")
                    .setMessage(result.message)
                    .setPositiveButton("去登录") { _, _ ->
                        TokenManager.clearToken()
                        LoginActivity.start(this@HomeActivity)
                        finish()
                    }
                    .setCancelable(false)
                    .show()
            }
            is ValidationResult.Error -> {
                toast(result.message)
            }
        }
    }
}
```
