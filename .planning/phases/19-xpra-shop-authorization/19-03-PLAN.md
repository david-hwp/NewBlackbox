<threat_model>
## Sensitive Data

Remote browser profiles may contain platform cookies and tokens. Probe code must treat profile storage as sensitive and only emit redacted signals.

## Mitigations

- Never log cookie or token values.
- Store only status, timestamp, and summarized evidence.
- Keep shop-specific stream URLs bound to phone/shop profile context.
- Restrict admin open/probe operations to super admin where required.
</threat_model>
