<objective>
Implement mandatory user login with phone number OTP. Manage JWT tokens (access + refresh) with automatic refresh. Register a session with the Engine APK after login so the Engine knows the host is authorized.

Purpose: All billing and user-specific features depend on having a logged-in user. The login system must be robust, secure, and seamless.

Output: A working login flow where users must authenticate before accessing any Engine features.
</objective>

  <name>Task 3: Implement AuthManager</name>
  <files>
    app/src/main/java/top/niunaijun/blackboxa/biz/auth/AuthManager.kt
  </files>
  <description>
    1. Create `AuthManager` singleton with:
       - `login(phone: String, otp: String): Result<UserProfile>`
       - `logout()`
       - `isLoggedIn(): Boolean`
       - `getCurrentUserId(): String?`
       - `ensureValidToken(): Result<String>` — returns valid access token, refreshing if needed
    2. `login()` flow:
       a. Call `AuthApi.login(LoginRequest(phone, otp, deviceId))`
       b. On success: store tokens in TokenStorage
       c. Register session with Engine: `EngineProxy.registerSession(sessionId, expireAt)`
       d. Return UserProfile
    3. `ensureValidToken()` flow:
       a. Check if access token expired
       b. If expired: call `AuthApi.refresh(refreshToken)`
       c. Store new tokens
       d. Return valid access token
    4. `logout()` flow:
       a. Clear TokenStorage
       b. Unregister Engine session: `EngineProxy.unregisterSession()`
       c. Navigate to LoginActivity
  </description>
</task>

  <files>
    app/src/main/java/top/niunaijun/blackboxa/biz/auth/AuthInterceptor.kt
  </files>
  <description>
    1. Create `AuthInterceptor` implementing OkHttp `Interceptor`
    2. For every outgoing request:
       a. Get access token from TokenStorage
       b. Add header: `Authorization: Bearer {token}`
       c. Add header: `X-Device-Id: {deviceId}`
    3. Handle 401 responses:
       a. Try refresh token
       b. If refresh succeeds: retry original request with new token
       c. If refresh fails: clear tokens, redirect to LoginActivity
    4. Attach to OkHttp client used by Retrofit
  </description>
</task>
