  <action>
    Create `ShopIdManager.java` as a singleton orchestrator for async shop ID extraction:

    **Class design**:
    - `private static final ShopIdManager sInstance = new ShopIdManager()`
    - `private final Handler mBgHandler` — background thread Handler (create new HandlerThread("ShopIdExtractor", Process.THREAD_PRIORITY_BACKGROUND))
    - `private final Map<String, Long> mLastExtractTime` — per-package last extraction timestamp (for throttling)
    - `private static final long EXTRACT_THROTTLE_MS = 30000` — 30 second minimum between extractions per D-04

    **Public methods**:
    - `public static ShopIdManager get()` — returns singleton
    - `public void triggerExtract(String packageName, int userId, Context context)` — main entry point
      1. Check if `ShopIdExtractorRegistry.hasExtractor(packageName)` — return early if none
      2. Check throttle: if `System.currentTimeMillis() - mLastExtractTime.getOrDefault(key, 0L) < EXTRACT_THROTTLE_MS`, return early
      3. Post to mBgHandler: run extraction
      4. In background: call `ShopIdExtractorRegistry.getExtractor(packageName).extract(context, userId)`
      5. If result is non-null: call `BPackageManagerService.get().updateShopInfo(packageName, userId, result)`
      6. Update `mLastExtractTime.put(key, System.currentTimeMillis())`

    - `public ShopInfo getShopInfo(String packageName, int userId)` — reads from BPackageManagerService

    **Key format for throttle map**: `"{packageName}#{userId}"`

    Per D-04 (trigger timing): This class handles the async + throttle logic. Callers (BActivityThread, UI) simply call `triggerExtract()`.
  </action>

    **Part A: BPackageManagerService extensions**
    Add three new public methods to `BPackageManagerService`:

    1. `public ShopInfo getShopInfo(String packageName, int userId)`:
       - Look up `BPackageSettings ps = mPackages.get(packageName)`
       - If ps is null, return null
       - Read `BPackageUserState state = ps.readUserState(userId)`
       - If `state.shopId` is null, return null
       - Return `new ShopInfo(state.shopId, state.shopName, state.platform)` with `state.shopId` as the shopId

    2. `public void updateShopInfo(String packageName, int userId, ShopInfo shopInfo)`:
       - Look up `BPackageSettings ps = mPackages.get(packageName)`
       - If ps is null, return
       - Get `BPackageUserState state = ps.modifyUserState(userId)`
       - Set `state.shopId = shopInfo.shopId`, `state.shopName = shopInfo.shopName`, `state.platform = shopInfo.platform`
       - Call `ps.save()` to persist
       - Slog.d(TAG, "Updated shop info for " + packageName + ": " + shopInfo.shopId)

    3. `public void clearShopInfo(String packageName, int userId)`:
       - Look up settings, modify user state, set shop fields to null, save

    **Part B: BActivityThread trigger wiring**
    In `BActivityThread.handleBindApplication()`, after the line `onAfterApplicationOnCreate(packageName, processName, application);` (around line 479), add:
    ```java
    // Trigger async shop ID extraction per D-04
    try {
        ShopIdManager.get().triggerExtract(packageName, BActivityThread.getUserId(), application);
    } catch (Exception e) {
        Slog.w(TAG, "Failed to trigger shop ID extraction for " + packageName, e);
    }
    ```
    Import `top.niunaijun.blackbox.core.system.pm.ShopIdManager` at the top of BActivityThread.

    **Part C: InstalledPackage extension**

    ```java
    public ShopInfo getShopInfo() {
        return BlackBoxCore.getBPackageManager().getShopInfo(packageName, userId);
    }
    ```
    This allows the app layer to easily access shop info for an installed package.

    Per D-04: trigger on app launch completion. Per D-05: data stored in BPackageManagerService.
