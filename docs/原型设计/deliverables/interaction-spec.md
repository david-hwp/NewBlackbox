# 多店管家 — 交互规范

> 版本：v1.0 | 平台：Android | 最小触摸目标：48dp

---

## 1. 全局交互规则

### 1.1 触摸目标

所有可点击元素最小触摸目标为 **48dp × 48dp**。视觉上小于 48dp 的元素，需通过扩大点击热区实现。

### 1.2 点击反馈

| 组件类型 | 默认反馈 | 按下态 |
|----------|---------|--------|
| 主按钮 | scale 1.0 | scale 0.98，背景加深 |
| 次要按钮 | 无 | 背景变暗 |
| 菜单项 | 无 | 背景 `--bg` |
| 卡片 | 无 | 无（滑动优先） |
| 链接/文字 | 无 | opacity 0.7 |
| 底部Tab | 无 | opacity 0.7 |

### 1.3 页面转场

| 转场类型 | 动画 | 时长 |
|----------|------|------|
| 登录 → 首页 | 淡入 + 轻微上滑 | 250ms |
| 首页 → 子页 | 从右向左推入 | 200ms |
| 子页 → 返回 | 从左向右推出 | 200ms |
| 底部抽屉弹出 | 从底部滑入 | 300ms |
| 底部抽屉关闭 | 向底部滑出 | 200ms |
| Toast 出现 | 淡入 | 150ms |
| Toast 消失 | 淡出 | 150ms |

### 1.4 转场动画曲线

- **标准 easing**：`cubic-bezier(0.32, 0.72, 0, 1)` — 抽屉弹出
- **弹窗 easing**：`cubic-bezier(0.16, 1, 0.3, 1)` — 底部确认弹窗
- **弹性 easing**：`cubic-bezier(0.32, 0.72, 0, 1)` — 滑动回弹

## 2. 首页交互

### 2.1 平台切换

```
触发：点击左侧平台栏任意平台项
行为：
  1. 被点击项添加 active 态（背景 #e8f5e9 + 左侧绿色指示条）
  2. 其他项移除 active 态
  3. 右侧店铺列表重新渲染，显示选中平台下的店铺
  4. 店铺列表标题更新为平台名称
  5. 店铺数量更新
动画：无（即时响应）
```

### 2.2 店铺卡片左滑

```
触发：手指在卡片上水平向左滑动 / 桌面鼠标按住向左拖动
行为：
  1. 手指按下记录起始 X 坐标
  2. 水平移动时，卡片 content 层实时跟随手指 translateX
  3. 垂直移动距离 > 水平移动距离 → 取消滑动，交给页面滚动
  4. 向右滑动超过 5px → 取消滑动，收起已展开卡片
  5. 松开手指：
     - 滑动距离 > 68dp（1/3 操作区宽度）→ 展开至 204dp
     - 滑动距离 ≤ 68dp → 回弹收起
  6. 滑动结束后 80ms 内阻止 click 事件（防误触）

展开态：
  ┌────────────────┬──────┬──────┬──────┐
  │ 卡片内容       │ 编辑 │自动续│ 删除 │
  │ (translateX)   │ 灰色 │ 绿色 │ 红色 │
  └────────────────┴──────┴──────┴──────┘

收起其他：滑动任一卡片时，自动收起其他已展开卡片
点击空白：点击列表中非卡片区域，收起所有展开卡片
```

**技术参数：**
- 最大展开距离：204dp（3 × 68dp）
- 展开阈值：68dp（1/3 最大距离）
- 实时滑动：transition none（手指移动时无动画）
- 回弹/展开动画：transform 0.28s `cubic-bezier(0.32, 0.72, 0, 1)`
- 滑动结束后 click 拦截：80ms

### 2.3 点击店铺打开APP

```
触发：点击店铺卡片的 Logo、名称或剩余天数区域（非滑动状态）
行为：
  1. 防误触检查：若 80ms 内刚结束滑动，忽略此次点击
  2. 显示 Toast：「正在打开 {平台名} APP…」
  3. 实际行为：通过 Deep Link 或 Intent 唤起对应平台商家版 APP
     - 美团外卖 → 美团外卖商家版
     - 淘宝网购 → 千牛/淘宝商家版
     - 京东闪送 → 京东秒送商家版
     - 快手小店 → 快手小店商家版
     - 小红书 → 小红书商家版
     - 阿里本地 → 阿里本地通
动画：Logo scale 0.95 按下反馈
```

### 2.4 左滑操作按钮

#### 编辑按钮
```
触发：左滑展开后点击「编辑」按钮
行为：
  1. 收起滑动菜单
  2. 弹出「编辑店铺名称」底部抽屉
  3. 输入框预填当前店铺名称
  4. 自动聚焦输入框（弹出软键盘）
  5. 用户输入新名称后点击「保存」
  6. 校验非空 → 更新数据 → 刷新列表 → Toast「店铺名称已更新」
```

#### 自动续时按钮
```
触发：左滑展开后点击「自动续时」按钮
行为：
  1. 收起滑动菜单
  2. 切换 autoRenew 布尔值
  3. 刷新列表（右上角三角标显示/隐藏）
  4. Toast：「「{店铺名}」自动续时已{开启/关闭}」
状态：
  - 关闭态：按钮文字「自动续时」，背景 `--accent`
  - 开启态：按钮文字「已开启」，背景 `#047857`
```

#### 删除按钮
```
触发：左滑展开后点击「删除」按钮
行为：
  1. 收起滑动菜单
  2. 弹出底部删除确认抽屉
  3. 显示文案：「删除后该店铺将不再出现在列表中，未到期但已扣除的算力不予退还，确定删除「{店铺名}」？」
  4. 用户点击「确认删除」
     - 从数据中移除该店铺
     - 更新平台计数
     - 刷新列表
     - Toast「已删除「{店铺名}」」
  5. 用户点击「取消」
     - 关闭抽屉，无其他操作
```

### 2.5 搜索过滤

```
触发：在搜索框输入文字
行为：
  1. 实时过滤（input 事件，无需防抖）
  2. 匹配规则：店铺名称包含关键字 或 店铺ID包含关键字（不区分大小写）
  3. 无结果时显示空状态：「没有找到匹配店铺」+ 空图标
  4. 清空搜索框后恢复完整列表
```

### 2.6 添加店铺

```
触发：点击底部「添加店铺」按钮
行为：
  1. 显示 Toast：「添加店铺功能开发中」
  2. 不展开任何表单或抽屉（当前版本仅保留入口）
```

### 2.7 首次使用提示

```
触发：首页首次加载且店铺列表非空
行为：
  1. 显示浮动提示：「左滑可编辑、删除或设置自动续时」
  2. 位置：屏幕底部偏上（距离底部 72dp）
  3. 样式：背景 rgba(0,0,0,0.7)，白色文字 12sp，圆角 20dp
  4. 2.5 秒后自动淡出消失
  5. 本地标记已显示，后续不再出现
```

## 3. 个人中心交互

### 3.1 修改用户名

```
触发：点击用户名右侧铅笔图标
行为：
  1. 弹出「修改用户名」底部抽屉
  2. 输入框预填当前用户名
  3. 自动聚焦（弹出软键盘）
  4. 用户输入后点击「保存」
     - 校验非空
     - 更新用户名显示
     - 关闭抽屉
     - Toast「用户名已更新」
  5. 支持回车键保存
```

### 3.2 修改密码

```
触发：点击「修改密码」菜单项
行为：
  1. 弹出「修改密码」底部抽屉
  2. 两个 password 输入框清空
  3. 自动聚焦第一个输入框
  4. 用户输入后点击「确定修改」
     - 校验1：新密码不能为空
     - 校验2：密码长度 ≥ 6 位
     - 校验3：两次输入一致
     - 任一校验失败 → Toast 提示错误，不关闭抽屉
     - 全部通过 → 关闭抽屉 → Toast「密码修改成功」
```

### 3.3 图片上传（问题反馈）

```
触发：点击上传网格中的「+」槽
行为：
  1. 模拟图片选择（实际开发应唤起系统相册/相机）
  2. 添加彩色占位块到网格（#f0f9ff, #f0fdf4, #fefce8, #fdf2f8 循环）
  3. 已上传图片右上角显示「×」删除按钮
  4. 最多 4 张，满后隐藏「+」槽
  5. 点击「×」删除对应图片

触发：点击「提交」按钮
行为：
  1. 校验反馈文本非空
  2. Toast：「反馈已提交（含 X 张图片）」
  3. 清空文本框和图片
```

### 3.4 底部导航

```
首页 Tab：点击跳转 HomeActivity
我的 Tab：当前页，无需跳转
选中态：icon + label 颜色变为 --accent
未选中态：icon + label 颜色为 --muted
```

## 4. 算力赠送交互

### 4.1 表单校验

```
触发：点击「确认赠送」按钮
前置校验：
  1. 对方手机号为空 → 聚焦手机号输入框，不弹窗
  2. 赠送数量为空或 ≤ 0 → 聚焦数量输入框，不弹窗
```

### 4.2 二次确认弹窗

```
触发：表单校验通过后点击「确认赠送」
行为：
  1. 弹出底部确认弹窗（遮罩 fade in + sheet slide up）
  2. 显示信息：
     - 我的账号：138****5678
     - 对方账号：{输入手机号脱敏显示 159****xxxx}
     - 赠送数量：{输入数量}（高亮绿色 20sp）
  3. 点击「取消」→ 关闭弹窗，保留表单数据
  4. 点击遮罩 → 关闭弹窗
  5. 点击「确认赠送」→
     - 关闭弹窗
     - 按钮变为「赠送成功」，背景变绿（#16a34a）
     - 1.5 秒后自动重置：
       - 按钮恢复「确认赠送」
       - 背景恢复 `--accent`
       - 清空两个输入框
```

### 4.3 手机号脱敏规则

```
输入：11位手机号
显示：前3位 + **** + 后4位
示例：13812345678 → 138****5678
正则：/^(\d{3})\d{4}(\d{4})$/ 替换为 $1****$2
```

## 5. 交易日志交互

### 5.1 筛选切换

```
触发：点击顶部筛选标签（全部/转出/转入/消耗）
行为：
  1. 被点击标签添加 active 态（背景 #1e293b，白色文字）
  2. 其他标签移除 active 态
  3. 下方日志列表按类型过滤
  4. 无动画，即时响应
```

### 5.2 日志数据结构

```kotlin
data class LogEntry(
    val id: String,              // 唯一ID
    val type: LogType,           // CONSUME / OUT / IN
    val date: String,            // 日期分组用 "2026-05-19"
    val time: String,            // 显示用 "16:30:00"
    val amount: Int,             // 数值（消耗/转出为负，转入为正）
    val platform: String?,       // 消耗类型：关联平台
    val shopName: String?,       // 消耗类型：关联店铺
    val fromPhone: String?,      // 转出/转入：转出方手机号
    val fromName: String?,       // 转出/转入：转出方姓名
    val toPhone: String?,        // 转出/转入：接收方手机号
    val toName: String?          // 转出/转入：接收方姓名
)

enum class LogType {
    CONSUME,   // 消耗
    OUT,       // 转出
    IN         // 转入
}
```

### 5.3 金额显示规则

| 类型 | 前缀 | 颜色 |
|------|------|------|
| 消耗 | `-` | `#0284c7` (info) |
| 转出 | `-` | `#d97706` (warn) |
| 转入 | `+` | `#059669` (accent) |

## 6. 状态与生命周期

### 6.1 数据持久化

| 数据 | 存储方式 | 说明 |
|------|---------|------|
| 店铺列表 | 服务端 API + 本地缓存 | 每次切换平台从缓存读取，后台同步 |
| 用户信息 | SharedPreferences | 用户名、手机号 |
| 算力余额 | 服务端实时获取 | 首页/赠送页/个人中心均显示最新值 |
| 交易日志 | 服务端分页加载 | 按日期分组，支持下拉刷新 |
| 首次滑动提示 | SharedPreferences | `hint_shown` 布尔值 |
| 登录态 | EncryptedSharedPreferences | Token，过期后跳转登录页 |

### 6.2 页面状态恢复

```
HomeActivity：
  - 恢复当前选中平台
  - 恢复搜索框内容（如有）
  - 恢复滚动位置

LogsActivity：
  - 恢复当前筛选类型
  - 恢复滚动位置

TradeActivity：
  - 不恢复（表单清空）
```

### 6.3 错误处理

| 场景 | 处理方式 |
|------|---------|
| 网络请求失败 | Toast「网络异常，请稍后重试」+ 重试按钮 |
| 店铺列表加载失败 | 显示重试占位图 + 「点击刷新」按钮 |
| 算力赠送失败 | 弹窗提示具体错误（余额不足/对方不存在等） |
| 删除店铺失败 | Toast「删除失败，请重试」 |
| 密码修改失败 | 抽屉内显示红色错误文字 |

| 页面推入 | 200ms | ease-out | translateX |
