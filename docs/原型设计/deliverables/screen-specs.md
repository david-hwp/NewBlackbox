## 屏幕 1：登录页 `LoginActivity`

### 页面结构

```
┌─────────────────────────────┐
│                             │
│         [Logo]              │  ← Logo区域 (flex: 1, 垂直居中)
│        多店管家             │
│    多平台店铺一站式管理      │
│                             │
│                             │
├─────────────────────────────┤
│ 账号 / 手机号               │  ← 表单区域 (白色卡片, 顶部圆角 24dp)
│ ┌─────────────────────────┐ │
│ │ 请输入账号或手机号       │ │  ← 输入框高 48dp, 圆角 12dp
│ └─────────────────────────┘ │
│ 密码                        │
│ ┌─────────────────────────┐ │
│ │ 请输入密码               │ │  ← type="password"
│ └─────────────────────────┘ │
│                             │
│ ┌─────────────────────────┐ │
│ │         登录             │ │  ← 主按钮 52dp 高
│ └─────────────────────────┘ │
│                             │
│   首次使用？请联系管理员开通账号 │  ← 13sp, --muted
└─────────────────────────────┘
```

### 详细标注

| 元素 | 尺寸 / 位置 | 样式 |
|------|------------|------|
| 页面背景 | 全屏 | `--bg` #f5f6f8 |
| Logo 图标 | 72dp × 72dp | 背景 `--accent` #059669，圆角 16dp |
| Logo 内图标 | 40dp × 40dp | 白色，SVG（多店铺图标） |
| APP名称 | 24sp，Weight 700 | `--fg` #1e293b，letter-spacing -0.02em |
| 标语 | 14sp，Weight 400 | `--muted` #64748b |
| 表单区域 | 全宽，顶部圆角 24dp | 白色背景，阴影 `0 -4px 20px rgba(0,0,0,0.04)` |
| 表单内边距 | 24dp 水平 | - |
| 字段标签 | 13sp，Weight 500 | `--fg-2` #475569，底部 margin 6dp |
| 输入框 | 宽 100%，高 48dp | 背景 #f8f9fa，边框 1.5px #e2e8f0，圆角 12dp，文字 16sp |
| 输入框聚焦 | - | 边框 #059669，外发光 0 0 0 3px #d1fae5 |
| 字段间距 | 16dp | - |
| 登录按钮 | 宽 100%，高 52dp | 背景 #059669，白色文字 16sp Weight 600，圆角 12dp |
| 登录按钮按下 | - | 背景 #047857，scale 0.98 |
| 底部提示 | 13sp | `--muted`，居中对齐，margin-top 20dp |

### 状态说明

- **初始态**：两个输入框为空，登录按钮可点击（点击后校验）
- **聚焦态**：对应输入框边框变绿 + 外发光
- **按下态**：按钮 scale 0.98，背景变深
- **加载态**：按钮文字变为「登录中…」，禁用交互
- **错误态**：输入框边框变红，下方显示红色错误提示
